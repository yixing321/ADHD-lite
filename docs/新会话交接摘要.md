## 0. 一句话现状

**331.5 KB 原生 WPF exe（C# 5 / .NET Framework 4.8）+ 44.6 KB Android APK（versionCode 18）。v0.11.6 针对 iQOO/Android 16 修键盘遮挡：`visualViewport` 不收缩时，MainActivity 用原生 `WindowInsets.Type.ime()` + `getWindowVisibleDisplayFrame()` 算可见高度，通过 `adhdSetVisibleHeight()` 把截止弹层抬到键盘上方；桌面 exe 仍是 v0.11.0。**
桌面仍是单进程、无后台服务：电脑上的提醒要程序开着；手机提醒是本地闹钟，电脑关机也能响。没有屏幕上下文，也不做自动排一天。

### 关键交互（改代码前必须知道）

1. **热键 `Ctrl+Num+`**：启动时 `EnsureHandle` + 立即注册（不是等录入窗显示）。降级态不会写进设置。
2. **录入窗**：写标题 → 选截止（今天/明天/5 分钟/10 分钟/自定义[延时|指定日期]）→ 选重要度 `Ctrl+1/2/3` → `Enter` 保存。
   默认截止时间由设置页「默认时间」决定（现在是"延时 5 分钟"）。
3. **提醒窗**：屏幕正中弹出、可拖动、不抢焦点；`开始做` / `完成`(Enter) / `稍后 N 分钟` / `自定义…` / `忽略`(Esc)。
   高 520px 红棕边「重要」/ 中 480px / 低 440px 灰边「顺手」（低隐藏开始做和自定义）。
4. **主界面**：左侧清单/月历/**复盘**/设置；窗口可拖四边四角缩放；小绿球右键也有入口。
5. **月历**：点月份标题可选年月；点格子选中那天，下方列出当天任务（编辑/改期/完成/删除）。
6. **AI 拆解**：录入窗页脚 `AI 拆解` → 结果窗勾选 → 全部加入。
7. **现在做哪件**：清单顶部；`开始做 / 换一个 / AI 帮我选`；下面一行是 `AI 计划：… · 下次 HH:mm` + `重排`；开始后变「正在做」条。
8. **复盘**：左侧「复盘」→ 统计 + 习惯画像 + `让 AI 看看这周`（结论写回 `settings.lastInsight`，影响之后所有 AI 提示词）。
9. **AI 提醒计划**：启动 / 任务签名变化 / 12 小时过期时生成，存在 `data\pushplan.json`；到点弹汇总窗，到期弹「已经到期」汇总。旧逐条提醒在计划生效时被抑制，手动「稍后」仍弹。
10. **v0.7 助理动作**：`拆小`（拖延≥2 次的任务行）/ `AI 取舍`（超载时）/ `下一步`（带备注开始任务时 AI 生成）/ `按类型`（写作/代码/沟通/杂事/学习/其他）/ `个人规则`（AI 复盘提炼，存 `settings.rules`）/ 录入查重与含糊提示。
11. **主题**：5 风格 ×4 色 = 20 套；科幻/简约有独立侧栏底色；`Deco.cs` 19 种矢量纹样，用在侧栏、页面标题、主题色块、录入窗右上角、设置页右侧留白、清单统计行/空态。
12. **开机自启**：设置 →「启动」→ 点亮；写 HKCU Run 的 `ADHD-lite` = `"<exe>" --startup`。`--startup` 静默启动：不弹主界面/气泡，只留托盘和悬浮球；已有实例则安静退出。移动 exe 后下次启动自动更新路径。
13. **手机同步**：设置 → 最底部「手机 / 同步」→ 点亮；桌面在 `0.0.0.0:17890` 起 TcpListener HTTP API，手机 APK 填 `http://100.x:17890` + 令牌。手机只拿任务，不拿 Key；AI 请求由桌面执行。Android 端同步后把未完成任务和 `pushPlan` 的 AI 计划写进 AlarmManager，**本地通知不依赖电脑开着**。
14. **手机外观/更新（v0.11.2）**：4 种底色（柔和/冷白/素雅/墨夜）× 6 个强调色（青瓷/雾蓝/暖砂/梅子/赤陶/松烟）；墨夜固定深色；默认柔和暖砂浅色；localStorage 独立。页头/统计/分页/任务标签/按钮/留白纹样都跟色。设置页有「← 返回主界面」、App 版本、通知/通道/响铃/精确闹钟/后台状态；电脑端 `/state` 带 `apkVersion`，手机可从桌面 `/apk` 一键下载安装。
15. **手机截止（v0.11.4）**：主界面只显示一个「今天 23:59 ▾」按钮；点开底部弹层分三页：
   - 快速：15/30/60/180 分钟、明天 09:00/21:00、后天 09:00，一点即设；
   - 延时：− / 数字 / ＋（分钟步长 5，小时/天 1）+ 常用 5/10/15/30/60/120 + 单位分钟/小时/天 + 实时预览；
   - 指定：今天/明天/后天/选日期 + 09:00/12:00/18:00/21:00/23:59/选时间，原生输入框只在需要时出现。
   - v0.11.6：输入框 focus 时优先 `window.visualViewport`；Android 16/iQOO 上它不收缩时，MainActivity 用 `WindowInsets.Type.ime()` + `getWindowVisibleDisplayFrame()` 算可见高度，调用 `window.adhdSetVisibleHeight()` 抬升弹层；关闭/失焦复位。
16. **手机通知**：通道 `adhd_alarm_v1` 用系统闹铃声音 + 长震动 + 锁屏可见；设置页「通知通道设置」可打开横幅/声音/震动。测试通知用 Handler 5 秒直发，不走 AlarmManager。
17. **手机点按反馈/连接诊断**：按钮/分页/任务按下缩放变暗；操作先 toast「正在…」、完成后提示；`busy` 时点按提示「正在同步」。设置页「连接诊断」分开显示 `/health` 和 `/state` 结果。
18. **Windows 防火墙**：本机已加 `ADHD-lite mobile sync (TCP 17890)` 入站规则（TCP，RemoteIP=100.64.0.0/10,LocalSubnet，Any profile）；手机连不上先查这条。
19. **退后台提醒（v0.11.3）**：`AlarmScheduler.schedule()` 优先 `setAlarmClock`（系统闹钟），失败回退精确/普通闹钟；通知带 `setFullScreenIntent`，点开/全屏由 MainActivity 带 `taskId` 调 `window.adhdFocusTask` 弹「到点了」。设置页「后台自检（30 秒）」走真实 AlarmManager，用来验证划掉 App 后还响不响。

## 3. 改代码前必须知道的 8 个坑（都是踩过的）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | `build.cmd` **必须 CRLF** 换行，LF 会被 cmd 切坏 | 改完用 `-replace "\r\n","\n" -replace "\n","\r\n"` 归一 |
| 2 | 改了 `ui\*.xaml` 但没重生成 `src\Ui.cs` → 界面不生效 | 跑 `powershell -ExecutionPolicy Bypass -File tools\gen-ui.ps1` |
| 3 | `VisualTreeHelper.GetParent(Run)` 抛异常（点按钮文字崩） | 用 `SafeParent()`（ContentElement 走 `ContentOperations.GetParent`） |
| 4 | 分段/胶囊按钮的选中态被 `MouseLeave` 抹掉 | 用 `Pill()` / `SegPill()`，**不要**用 `TinyButton` 做选中态（清单分页已从 TinyButton 改为 SegPill，见 `TAB-HIGHLIGHT` 自检） |
| 5 | `Track` 不能 `FrameworkElementFactory.AppendChild`（滚动条） | 用 XAML 字符串 + `XamlReader.Parse` |
| 6 | 主界面骨架（侧栏/品牌字/标题/叉号）只在建窗时上色 → 换主题不变 | 在 `ApplyTheme()` 里调 `RepaintMainChrome()` |
| 7 | 无边框 + `AllowsTransparency` → WPF 自带缩放失效 | 用 8 个 6px 透明热区（`EnableResize`/`AddGrip`，Tag="grip"） |
| 8 | 稍后/改期后不再提醒（真 bug，两个原因） | ① 清 `fireDay/fireCount` ② `SchedulePreciseReminder` 要看"最近的未触发提醒点"而不是只看 `due` ③ 稍后之后 `overdueDay` 设为今天，否则心跳会顶回来 |
| 9 | 截图/自检里的演示任务被退出时的"暂停计时"写进真实 `tasks.json` | 截图模式设 `selftesting = true`，`PauseActiveForExit()` 直接 return；自检任务只落 `%ADHD_HOME%` |
| 10 | AI 计划生效后旧逐条提醒还在弹 → 一次任务被提醒两次 | `Tick()` 里 `planOn` 时把非「稍后提醒」的槽位标 fired 并跳过；手动稍后不受影响 |
| 11 | 到期汇总把"没截止的任务"也算进"已到期" | `ShowDigest()` 的 overdue 分支只从 `due < now` 里取 pool；数量/行/焦点都用这个 pool |
| 12 | 手机设置页被 3 秒轮询关掉 | `render()` 不能无条件 `setupVisible(false)`；用 `inSettings` 状态，只有用户点返回才关 |
| 13 | 手机主题切换后按钮文字看不清 | 强调色可能偏亮，用 `contrastOn()` 算 `--accentTxt`，不要写死 `#fff` |
| 14 | 手机更新装不上 | `versionCode` 必须递增；`debug.keystore` 不变；`/apk` 只认 exe 旁边 `android\dist\ADHD-lite-android-v*.apk`；Android 8+ 还要允许「安装未知应用」 |

**其它约定**
- 设置版本号现在是 `ver = 9`；加字段直接加属性（JavaScriptSerializer 缺字段走构造函数默认值）。改动默认值才需要升 ver + 写迁移。
- **测试模式隔离**：`--selftest` / `--ui-selftest` / `--ai-smoke` 在没显式设 `ADHD_HOME` 时自动用 `%TEMP%\adhd-selftest-home`，只复制 `settings.json`（拿 Key/主题），不复制 tasks/pushplan，也不写注册表。别绕过这个入口。
- **日志脱敏**：`settings.json` 的 `aiKey` **和 `mobileToken`** 在 `startup.log` 里统一是 `***`；以后加日志也别打印。
- **手机端口**：默认 `17890`，绑定 `0.0.0.0`；手机访问用 Tailscale `100.x` 或局域网 `192.168/10.x`。不要暴露公网。
- **Android 构建坑**：`android\build-apk.ps1` 必须 UTF-8 **with BOM**（PowerShell 5.1 否则按 ANSI 读中文注释，`$root` 会莫名变空）；`aapt2` 不认中文路径，脚本先复制到 `%USERPROFILE%\AppData\Local\Temp\adhd-android-build` 再编译。
- **APK 升级签名**：保留 `android\debug.keystore`，换 key 会导致手机无法覆盖安装。
- v0.5 的任务字段：`startedAt`（>0 = 正在计时）、`spentMs`（累计实际）、`estimateMin`（预计）、`lastNote`、`snoozeCount`、`postponeCount`。**统计不另存**，全部从这些真实字段算。
- v0.6 的计划：`data\pushplan.json`（`PushPlan`/`PushItem`）；`PushItem.at` 是绝对毫秒，`kind` = nudge / overdue，`fired` 由调度器维护。
- `SaveSettings()` 只在 `hotkeyFromUser && hotkeyRegistered` 时才回写热键，其它情况只存主题等；**别再无条件写 `hotkeyMods`**（这是历史上"快捷键老是变回 Ctrl+="的根因）。
- 提醒额度：`DAILY_LIMIT = 2`，心跳 30 秒；两分钟内的提醒点会额外挂精确 `DispatcherTimer`（只对旧固定提醒生效，AI 计划走自己的 30 秒 Tick）。
- 主题 token：`Styles[风格][颜色]` = 11 个字段，访问器 `Accent/AccentSoft/AccentLine/AccentDeep/AccentBg/CardBg/TextMain/TextSub/TextMuted/LineCol`。**新 UI 一律用 token，不要写死颜色。**
