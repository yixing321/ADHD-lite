   - 旧版也能从设置页看到「电脑上有新版本」→「下载并安装」，桌面 v0.11.0 的 `/apk` 会把 v0.11.9 发过去。
2. **真机后台提醒（这轮重点）**
   - 点「后台自检（30 秒）」，30 秒内把 App 划掉或锁屏；应响铃 + 横幅 + 弹「到点了」。
   - 不响就依次看：精确闹钟（必须已允许）、电池不受限、全屏提醒（Android 14+）、系统自启动/后台弹出界面。
   - 点「测试通知（5 秒）」只验证通道；「后台自检」验证 AlarmManager + 退后台。
   - 如果测试弹但任务不弹：查 `/state` 是否返回任务、JS bridge 是否调用。
3. **手机/电脑双向同步**
   - 电脑加一条 → 手机 3 秒内出现；手机完成一条 → 电脑清单勾掉。
   - 手机断网用缓存，回连后 outbox 补发。
4. **AI 计划上手机**
   - 电脑「重排」后，手机 `/state` 应拿到 `plan`；到计划时间手机本地通知显示「AI 提醒」。
   - 若电脑关机，手机已排的闹钟仍应响。
5. **其他用户**
   - 同一 Wi-Fi 不需要 Tailscale，填 `192.168/10.x`。
   - 在外面用，对方手机也要装 Tailscale 并加入同一 tailnet；当前是**单一令牌**，能连的人都能读写全部任务。要做访客/多用户，需要单独 token 或公网中继（还没做）。

## 硬规则 / 工作流

- 编译：`cd D:\ADHD清单; cmd /c "build.cmd < nul"`，期望 `编译成功: ADHD-lite.exe`。
- 编译前检查 `Get-Process ADHD-lite`；用户可能正在用，锁住 exe 时才关（必要时 `taskkill /f`）。
- **`build.cmd` / `pack.cmd` 必须 CRLF**；`tools\pack.ps1`、`android\build-apk.ps1` 必须 **UTF-8 with BOM**（PowerShell 5.1 无 BOM 会把中文注释按 ANSI 解析，变量会空）。
- 改 `ui\*.xaml` 后必须跑 `tools\gen-ui.ps1`，再编译；不要手改 `src\Ui.cs`。
- 自检自动隔离，不需要手工设 `ADHD_HOME`：
  ```powershell
  .\ADHD-lite.exe --selftest
  .\ADHD-lite.exe --ui-selftest
  Get-Content "$env:TEMP\adhd-selftest-home\diagnostics.log"
  ```
  必须 0 FAIL。
- 截图：`--main-shot` / `--snapshot` / `--reminder-shot` / `--digest-shot` / `--dialog-shot`；改 UI 后重渲染并更新 README/docs。
- 新 UI 用主题 token；选中态用 `Pill` / `SegPill`，不要用 `TinyButton`。
- `data\` 有 Key 和手机令牌，已 gitignore；**绝不 `git add -f data/`**。
- 用户通常双击运行；Agent 启动的 GUI 会被回收，不要让用户以为程序坏了。
- C# 5 语法；不引入第三方依赖；保持桌面单 exe 便携。
- 每轮结束：编译 + 46/16 自检 + 相关截图 + 更新 `README.md` / `docs\现状与剩余任务.md`，再 commit。
- Android 构建：
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File android\build-apk.ps1
  ```
  SDK 在 `%USERPROFILE%\AppData\Local\Android\Sdk`（platform 35 / build-tools 35.0.0），JDK 22；`aapt2` 不认中文路径，脚本会先复制到 ASCII temp。
